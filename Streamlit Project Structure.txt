Layer notes:
- converters/: lightweight wrappers around existing converter scripts.
- extractors/: parser wrappers that return dataframes.
- transformers/: staging to DWH and mart transformations.
- validators/: data quality checks.
- loaders/: Parquet writing helpers.
- storage/: DuckDB, SQLite metadata, file hash, lineage, and path helpers.
- services/: Streamlit orchestration, ETL storage, cache, cleanup, logging, and error reports.
- dashboards/: Streamlit dashboard rendering.
- data/: local analytical storage; generated data files are ignored by Git.
- uploads/, temp/, cache/: working folders that can be cleaned safely from the app.
- outputs/: generated Excel, ZIP, and error report outputs.
